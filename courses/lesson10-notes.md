# 第十课｜天地人、八宅磁场与三元命的应用

## 一、同频共振与气场调和
- 同频共振，气场调和。
- 绝命磁场形象像一个爪子，有木与金打架、相互冲突的感觉。

## 二、齐物论、般若与智慧慈悲
### 庄子的思想
- 天均论（听课原记）、朝三暮四、《齐物论》。
- “天地与我并生，而万物与我为一。”
- 傲慢来自偏见，谦卑来自洞察。
### 般若与慈悲
- 般若：如实认知一切事物及万物本源的智慧。
- 有般若才有对无奈的理解与同情；同情生出愿意帮助大家的愿力，由此有慈悲。
- 智慧和慈悲并行，有此才有大愿，才有大行。
- 课堂脉络：般若 → 理解无奈 → 同情 → 慈悲；智慧与慈悲 → 大愿 → 大行。

## 三、天地人与易学的认知路径
- 课堂提及西方三圣与天地人、性格、行为、结果。
- 课件主线：天 → 地 → 人 → 智慧 → 道、齐物；“易学”标于智慧通往道的箭头下方。
| 层次 | 对应 |
|---|---|
| 天 | 性格 |
| 地 | 行为 |
| 人 | 结果 |
- 整理理解：由性格观察行为及其结果，进而理解规律。此句为整理归纳，不是老师逐字原话。
- 西方三圣具体对应关系尚待补充。

## 四、延年磁场
### 基本属性
- 大吉星；本位乾卦，西北，天，阳金，武曲星。
- 课件形态：米字形交叉线。
| 层次 | 课件取象 |
|---|---|
| 天·性格 | 威严、稳重、踏实；自我 |
| 地·行为 | 取得权贵、内外和顺皆兴旺、高高在上、早婚、人丁兴旺；不容挑战、打架 |
| 人·结果 | 催官、催婚、催孕、维稳 |
### 课堂补充
- 延年过重：孩子容易表现得自我、自以为是、不容挑战、打架。
- 人物取象：汉武帝、秦始皇、李世民、武则天。
- 课堂记忆：延年稳一稳就稳了。

## 五、生气磁场
### 基本属性
- 本位震卦，正东，阳木，贪狼星。
- 课件形态：四个箭头循环运行。
| 层次 | 课件取象 |
|---|---|
| 天·性格 | 积极向上、好德之心、德行端正 |
| 地·行为 | 好学、有文化、人缘好、有名望 |
| 人·结果 | 催事业、催文昌、催团队；正官、事业 |
### 课堂补充
- 人物取象：周总理、优秀的部门经理、导师。
- 生气过重：好高骛远、眼高手低、过于清高、死要面子。

## 六、天医磁场
### 基本属性
- 本位艮卦，东北，阳土、戊土；代表财富。
- 课件形态：倾斜的井字形。
| 层次 | 课件取象 |
|---|---|
| 天·性格 | 善良、忠厚、宽容 |
| 地·行为 | 身心健康、与宗教产生联系、有信仰、有技艺、出医卜僧道、有财富 |
| 人·结果 | 睡天医；休息、吃药、放保健品、住院床位；通神；厨、卧天医 |
### 课堂补充与应用
- 睡天医：课堂取象为休息好、精力易恢复。
- 生病时休息、吃药、放保健品、住院床位等是课件列出的传统取象，并非医疗建议。
- 厨、卧天医：课件取象为至少一人为医卜僧道。
- 供神可取天医位；如不具备条件，也可取延年、生气位，避免凶宫。
- 人物取象：张三丰、张仲景。

## 七、绝命磁场
### 基本属性
- 本位兑卦，正西，阴金；课件别称绝嗣。
- 形态取象：爪子、金木相争。听课笔记提到七赤破军。
| 层次 | 课件取象 |
|---|---|
| 天·性格 | 肃杀、冲突、急躁、急功近利 |
| 地·行为 | 对外冲突灾祸、官非口舌、短寿、不治之症；对内缺乏安全感、焦虑、子女缘薄、肝郁；家庭关系一般、子女外地发展 |
| 人·结果 | 催孕、绝命婚、睡绝命卧 |
### 卦象组合
| 卦象 | 数字 |
|---|---|
| 离配乾 | 96、69 |
| 坤配坎 | 21、12 |
| 兑配震 | 73、37 |
| 巽配艮 | 48、84 |
### 课堂婚育与国运取象
- 催孕：阴阳相合，女儿（易流），忌双绝命。
- 绝命婚：易头胎女儿；课堂强调不宜用于催婚。
- 睡绝命卧：子女缘薄、外出工作或上学。
- 人物取象：白起、杀神、残暴的将士、讲义气的黑道大哥。
- 七赤破军：老师将飞临方位与国运、战争相联系。
- 上述均为课堂传统术数说法，不可据此预测胎儿性别、流产、疾病、寿命或战争，也不可作为婚育及医疗决策依据。

## 九、三元命（风水命）与计算
- 三元命又称风水命；课堂提及野马跳涧、小开关。
- 第一步：求年命之和（个位数，以立春为界）。
- 第二步：男生 11－和；女生 4＋和。若所得为两位数，继续化为个位数。
- 第三步：以所得数字对应后天卦；最终命数为5时，男归坤二，女归艮八。
| 数字 | 卦象 |
|---|---|
| 1 | 坎 ☵ |
| 2 | 坤 ☷ |
| 3 | 震 ☳ |
| 4 | 巽 ☴ |
| 5 | 中宫（按上述规则处理） |
| 6 | 乾 ☰ |
| 7 | 兑 ☱ |
| 8 | 艮 ☶ |
| 9 | 离 ☲ |
### 课堂案例：1984年
- 1＋9＝10；8＋4＝12；化简为1、3；1＋3＝4。
- 男命：11－4＝7，兑。女命：4＋4＝8，艮。
- 兑 ☱ 与艮 ☶ 三爻全变，课堂称延年婚配，取象为稳定。
### 计算练习：1994年女性（立春后）
- 1＋9＝10；9＋4＝13；化简为1、4；1＋4＝5。
- 原听课练习记作艮八。按截图明确列出的女命公式复算：4＋5＝9，为离九。
- 这里5是年份数字之和，不是最终命数；此处为整理时的计算核对，不是新课堂内容。

## 十、三元命的三大应用
### 人与地：定人场
- 人与门：人的命卦与门的方位卦之间形成的磁场。
- 人与卦：课件列出的另一个定人场方向，具体操作待补充。
- 课堂案例：门乾六、人艮八，形成天医磁场。
### 人与天：看流年
- 天阳、地阴；天当男、地当女。
- 将流年与个人命卦结合，判断磁场。
- 课堂案例：2024年，2＋0＋2＋4＝8；按男性公式，11－8＝3，天运为震三。
- 若个人为坎一，与震三形成天医磁场，课堂取象为赚钱、有好的信仰、调整事业方向，以稳财、提升自己为主。
- 流月也可以看，课堂指出相关内容出自玄空风水；具体流月算法待补充。
### 人与人：看人与人关系
- 比较双方三元命形成的磁场关系。
- 婚配案例：兑七与艮八形成延年磁场，取象为稳定。
### 两套天地人框架（整理对照）
| 层次 | 磁场认知 | 三元命应用 |
|---|---|---|
| 天 | 性格 | 人与天：流年、流月 |
| 地 | 行为 | 人与地：人与门、人与卦 |
| 人 | 结果 | 人与人：人际关系 |
