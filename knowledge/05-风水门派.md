# 风水门派｜知识库重建稿

> 主要依据：易理基础知识卡PPT第16、17、19页，以及现有网站e1—e4、y1、y10条目。  
> 注意：本模块记录的是课程体系与现有笔记中的说法，不把不同门派强行统一，也不将课件中的术数判断表述为已验证的现实因果。

## 一、风水派别学习纲要

PPT第19页将学习内容按六个层次组织：

| 层次 | 课程所列派别 | PPT中的定位 |
|---|---|---|
| 骨架 | 七星蕴含 | 框架性、基础型入门风水学科，用于确定房屋宏观格局、规划内部功能区 |
| 肌肉 | 金锁玉关 | 课件又称“过路阴阳”，强调房屋能量分布判断与方向性调整 |
| 穴位 | 玄空飞星 | 课件描述为将风水能量与天运结合的技法，对周易素养要求较高 |
| 气血 | 形家风水 | 贯穿各派学习，重视大环境形势观察 |
| 法器 | 奇门风水 | 以奇门遁甲预测为基础，结合盘面信息讨论风水布局 |
| 外挂 | 三吉六秀 | PPT以杨公风水为代表，提到四十九宫实战技法，并注明秘法不详述 |

### 1. 骨架：七星蕴含

PPT原文要点：

- 框架性、基础型的入门风水学科。
- 用以确定房屋风水宏观格局，合理规划内部功能区。
- 课程称其可用于判断房屋吉位、凶位，并对房屋缺陷提出调解方案。
- PPT称其也是数字能量学科（手机号码、门牌号、车牌号等）的理论基础。

### 2. 肌肉：金锁玉关

PPT原文要点：

- 江湖又称“过路阴阳”。
- 课件强调其判断房屋吉凶能量分布和方向性调整的特点。
- PPT称其具有针对性和可操作性。

### 3. 穴位：玄空飞星

PPT原文要点：

- 将风水能量与天运结合。
- 课件称其核心技法对学习者的周易素养有较高要求。
- 学习方向：有较强学习意愿和主动性，根据课程参看相关古籍、研习案例。

### 4. 气血：形家风水

PPT原文要点：

- 贯穿各风水门派学习的始终。
- 重视大环境形势观察。
- 学习方向：在各派学习中积累，善于在生活中观察。

### 5. 法器：奇门风水

PPT原文要点：

- 课件将其与奇门遁甲预测、盘面信息及风水布局联系起来。
- 学习方向：以奇门遁甲预测为基础，通过盘例练习提高对盘面的理解。

### 6. 外挂：三吉六秀

PPT原文要点：

- 课件以杨公风水为代表。
- 提到四十九宫实战技法。
- PPT注明“属秘法范畴概不详述”。
