# 观道 · 风水知识库（v0.1）

第一版只整理本次提供的第八课风水内容。网站是纯静态 HTML，无需安装环境，解压后双击 `index.html` 即可预览。

## 已有功能
- 中式古典视觉：青绿、宣纸、鎏金配色
- 课程与知识分类
- 关键词搜索、分类筛选、常用知识标签
- 知识详情页
- 手机和电脑自适应布局

## 内容更新
第一版知识内容直接写在 `index.html` 的 `NOTES` 数组中。后续新增课程时，可复制一条知识对象并修改标题、摘要、标签和 sections。也可以把新课程材料发来，由我继续更新网站文件。

## 发布固定网址（GitHub Pages）
1. 在 GitHub 新建一个 **Public（公开）** 仓库，建议名称：`guandao-fengshui`。
2. 将本目录所有文件（包括 `.github` 文件夹）上传到仓库根目录。
3. 打开仓库 Settings → Pages，将 Source 选择为 **GitHub Actions**。
4. 在 Actions 页面确认工作流运行成功。
5. 发布成功后，网址通常是 `https://你的GitHub用户名.github.io/guandao-fengshui/`。

这是公开网页，知道网址的人都能访问。不要在其中放入住址、证件、医疗记录、账号密码等私人信息。
