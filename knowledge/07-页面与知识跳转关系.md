## 二、页面之间的跳转

### 2.1 总览页

总览页的五个知识模块卡片分别跳转：

- 易理根基 → `foundation`
- 干支与历法 → `branches`
- 卦象与方位 → `bagua`
- 风水门派 → `schools`
- 阳宅实操 → `yangzhai`

课程笔记入口跳转到 `courses`。

### 2.2 知识模块页

每个知识模块统一包含：

1. 模块说明。
2. 关键词搜索。
3. 按知识分组的筛选器。
4. 知识卡片列表。
5. 点击卡片打开详情。
6. 详情页中的相关知识跳转。

### 2.3 相关知识跳转

每张知识卡通过 `related` 保存关联条目的ID。详情页展示关联条目，点击后打开对应知识卡。

关系示例：

- 无极、太极、两仪、四象 → 八卦卦画、先后天八卦。
- 河图洛书 → 先后天八卦 → 九宫与二十四山。
- 天干五合、四冲 → 五行生克、干支关系总览。
- 十二地支 → 地支藏干 → 长生十二态。
- 地支关系总览 → 三合三会六合、六冲刑害破。
- 七星与八宫磁场 → 大游年歌 → 数字磁场。
- 风水门派纲要 → 七星蕴含、金锁玉关、玄空飞星、形家风水、奇门风水。
- 立极与几何中心 → 天心位 → 缺角缺宫 → 测方位 → 定磁场与定门。
- 阳宅三要 → 测方位与定门。

## 三、课程笔记与知识卡的关系

- 课程笔记按课次保存学习过程和资料出处。
- 知识卡按主题组织，允许跨课程归纳同一知识点。
- 课程笔记中出现的知识点应链接到主知识卡；知识卡的来源字段应指回课程笔记或PPT页码。
- 不因知识卡已整理，就删除课程笔记中的原始表述和老师举例。

## 四、术语索引的检索范围

术语索引覆盖：

- 知识卡标题。
- 知识卡摘要。
- 标签。
- 分组名称。
- 知识卡正文中的小标题和条目。

术语索引不另起一套解释；点击结果仍打开原知识卡，确保同一概念只有一个正文版本。

## 七、代码层面的统一规则

- 页面ID、导航ID、搜索状态、筛选状态必须一致。
- 每个模块的DOM容器命名统一为 `{view}Filters`、`{view}Cards`、`{view}Empty`。
- 所有知识卡ID唯一。
- `related` 中的每个ID必须存在于当前知识卡集合。
- 新增知识模块时，必须同步更新导航、页面容器、筛选状态、搜索绑定、`renderAll`和总览入口。
- 页面初始化时任一模块渲染失败，不应导致其他模块全部停止；后续可增加模块级错误隔离。

## 八、已修复的旧页面问题

旧版干支页面的HTML容器ID使用单数：

- `branchFilters`
- `branchCards`
- `branchEmpty`

但渲染函数按页面ID拼接，实际查找的是：

- `branchesFilters`
- `branchesCards`
- `branchesEmpty`

两者不一致，导致干支模块渲染时找不到容器，触发JavaScript错误，后续初始化流程中断。

本分支已将HTML容器统一为复数形式，并完成脚本语法检查、页面ID检查和关联ID检查。
