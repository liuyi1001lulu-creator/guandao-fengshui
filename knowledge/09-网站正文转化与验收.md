# 网站阅读功能与知识卡正文映射验收记录

> 分支：`rebuild/gan-zhi-v1`  
> 范围：八入口、五模块、37张知识卡、八课课程笔记及术语搜索。  
> **验证级别：JavaScript模拟DOM检查 + GitHub Actions真实Chromium桌面及手机浏览器验收通过。** 测试基于独立分支文件的本地HTTP服务；尚未部署为正式GitHub Pages网页，线上域名仍需发布后核验。

## 一、本次完成的页面升级

1. 新增 `knowledge-content.js`，从五份已经审校的Markdown专题文稿生成HTML正文。
2. 五大知识模块各增加“阅读完整专题”按钮，可按章节目录直接阅读所有内容。
3. 37张知识卡全部绑定专题中的对应章节；点击知识卡优先显示完整章节、表格与来源提示，而不是旧版简短摘要。
4. 旧版知识卡提要放入折叠区，不删除旧内容，同时避免同屏重复呈现。
5. 搜索范围扩充到知识卡对应章节的完整文字；术语索引也可搜索完整正文。
6. 所有知识卡支持Enter和空格键打开；表格提供横向滚动，适配窄屏阅读。
7. 第五课不再引用已合并的`b7`、`b8`、`f13`，改为对应仍存在的知识卡。
8. 第六、第七、第八课因原始专题文件未完整核实，展示为“部分整理”，不标成整课已完成。
9. 阳宅实操卡增加来源提示，避免把旧网页内容误认作已核验的老师原始课堂记录。

- **真实手机体验**：Chromium 390px布局测试及截图验收已通过；跨机型、字体和浏览器差异留待正式发布时抽查。

- **来源复核**：五份Markdown有待核实的小字、完整课件差异仍保留在[原始资料审校记录](08-原始资料审校记录.md)。
- **上线决策**：独立分支中的桌面与手机真实浏览器验收已通过；正式上线仍需内容最终审读、确认未上传图片路径和部署资源加载情况，再决定是否合并`main`。

## 六、维护约定

后续修改五份Markdown讲义时，必须**同步重新生成`knowledge-content.js`**，否则网页显示仍是旧版正文。不得直接修改网页生成正文而遗漏原始讲义文件。
