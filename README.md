# 观道 · 风水知识库（v0.2）

以课程为线索，以知识体系为纲的个人风水学习档案。当前为纯静态 HTML，无需安装环境。

## 网站栏目
- 总览：知识体系入口、近期新增内容
- 易理基础：无极太极、两仪四象、八卦、河图洛书、先后天八卦、五行
- 干支知识：十二地支、月份时辰生肖、天干五合四冲、三合三会六合、六冲六害刑破、地支藏干、长生十二态
- 七星与八宅：北斗七星、八宫磁场、大游年歌、乾卦爻变、数字磁场、三元命索引、风水派别学习纲要
- 阳宅实操：北派与南派、门主灶、藏风聚气、立极与几何中心、天心位、缺角补气、方位校准、定磁场定门、拱合论、口诀
- 课程档案：第一至第八课的资料状态
- 术语索引：跨栏目关键词检索

## 资料来源与整理原则
- 《2026-09易理基础知识卡修订版.pptx》
- 用户提供的十二地支图、地支关系图、罗盘图
- 用户提供的《阳宅风水｜立极、天心位与磁场判断》专题笔记
- 此前整理的第二、第三、第五至第八课课堂笔记

课程档案与知识条目分开管理；跨课程的同一知识点集中在知识体系中。课堂原话、个人理解、待核对内容尽量分开标注。长生十二态与三元命速查等图表先保留来源索引，不凭缩略图猜填细节。

## 内容更新
当前知识内容直接写在 `index.html` 的 `notes`、`lessons` 和 `glossary` 数组中。新增知识条目时，在 `notes` 数组追加对象；每条包含栏目、标题、摘要、标签、资料来源和分节内容。
