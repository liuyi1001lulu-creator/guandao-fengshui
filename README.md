# 观道 · 风水知识库（v0.4）

以课程为线索，以知识体系为纲的个人风水学习档案。网站为纯静态 HTML，无需安装环境。

## 网站栏目
- **总览**：知识体系入口、近期新增内容与学习概览
- **知识体系**：将不同课程的相关概念整合为“根本原理—变化规律—时空表达—空间应用”的学习脉络
- **易理基础**：阴阳、太极、三才、四象、八卦、河图洛书、先后天八卦、五行
- **干支知识**：十天干、十二地支、天干五合四冲、三合三会六合、六冲六害刑破、地支藏干、长生十二态
- **七星与八宅**：北斗七星、八宫磁场、大游年歌、乾卦爻变、数字磁场、三元命索引、风水派别学习纲要
- **阳宅实操**：北派与南派、门主灶、藏风聚气、立极与几何中心、天心位、缺角补气、方位校准、定磁场定门、拱合论、口诀
- **课程档案**：按课次阅读整理后的文字笔记，课程条目可跳转到对应知识内容
- **术语索引**：跨栏目检索知识概念，并定位相关条目

## 整理与整合原则
1. **不展示原始思维导图。** 思维导图只作为整理素材，网站最终呈现可独立阅读的文字内容。
2. **课程有出处。** 课程档案按课次保留来源；知识体系从不同课程中提取相同或相关概念。
3. **知识有联系。** 条目之间建立关联入口，便于从概念延伸到相关课程和应用。
4. **保留老师原意。** 尽量保留课堂术语、解释顺序和关键例子；不擅自改写成另一套理论。
5. **区分课堂内容与整理归纳。** 为了阅读而作的归纳会作为“知识关联”呈现，不伪装成老师原话。
6. **资料不足不猜填。** 不从模糊图像推断细节；未核实的内容标记待补，不用常识强行补全。

## 内容维护
网站采用“Markdown专题稿为维护源文件、JavaScript正文为网页载入内容”的方式：
- `knowledge/02-06*.md`：五个专题模块的正文维护稿；先在这里核对和修改知识。
- `knowledge-content.js`：网页实际载入的专题正文、章节目录和知识卡正文映射。修改Markdown后必须同步更新这里，不能只改其中一份。
- `index.html`：页面结构、课程目录、知识卡索引、搜索与交互逻辑。
- `knowledge-diagrams.js`：长生十二态、河洛、八卦等网页图表。
- `tests/site-check.cjs`：桌面与手机浏览器验收脚本。
- 第二课《阴阳之本》统一按“阴阳—太极—三才—四象—五行”五个主章节阅读，具体知识点在章节内逐层展开；单项知识仍保留在术语搜索与关联数据中。
